# Seguridad

Para comunicar una vulnerabilidad de forma privada, utiliza [Report a vulnerability](https://github.com/Sheily-AI/.github/security/advisories/new). Incluye el repositorio afectado, los pasos de reproducción, el impacto y las versiones implicadas. No publiques credenciales ni datos sensibles en issues o Discussions.

Cada repositorio puede definir su propia política de seguridad, que tiene prioridad sobre esta guía general. Las alertas automáticas no garantizan la ausencia de vulnerabilidades.
